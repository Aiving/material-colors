ColorSpec implementation for the 2026 spec.

This spec only declares color definitions; roles it doesn’t declare, the tone/HCT algorithm and the scheme palettes all come from 2025.

Only Variant::Cmf keeps spec 2026 (DynamicScheme::fallback_spec_version downgrades every other variant), so the else 0.0 branches below are dead in practice. They are kept for fidelity.
