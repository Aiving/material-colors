Enum DynamicColor

pub enum DynamicColor<'a> {
    Material(Role),
    Custom(&'a dyn CustomColor),
}
Expand description

A dynamic color: either a Material role (resolved through the scheme’s spec version) or a user-defined color.

pub const fn tone_prefers_light_foreground(tone: f64) -> bool

People prefer white foregrounds on ~T60-70. T60 itself is excluded since dark monochrome tertiary_container requires a tone of 60.

Source

pub const fn tone_allows_light_foreground(tone: f64) -> bool

Tones less than ~T50 always permit white at 4.5 contrast.
